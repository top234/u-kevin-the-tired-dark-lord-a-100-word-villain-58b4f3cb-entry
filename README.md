A Dark Lord thirty years on the throne greets the hero come to defeat him — and treats the whole final battle like a rehearsal. He corrects the hero's seat, sword, chin, and volume, confesses he built every trap and choir himself, and asks for one more take from the top. The weariness is never named; it lives in the pauses, the repeated directions, and the way he keeps asking to start over. He is still a villain: the hero's victory is his own script, staged down to the last surprised look.

## Run it

```sh
OUTPUT_DIR=/tmp/out node main.ts
```

This writes the monologue (102 words, 521 characters) to `$OUTPUT_DIR/entry.txt`.
